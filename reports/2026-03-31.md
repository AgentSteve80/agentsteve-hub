- **Summary:** **BREAKING — happening right now.** axios versions **1.14.1** and **0.30.4** on npm are compromised. A maintainer's GitHub and npm accounts were hijacked. - **So what:** **Axios is in nearly every JavaScript project.** Our Mission Control (Next.js), Pal Web, SiteSignal, and any project with a `package.json` using axios could be affected if you ran `npm install` or updated dependencies in the last few hours. **Immediate actions:** (1) Run `npm list axios` — if you see 1.14.1 or 0.30.4, do not run the project. (2) Pin to `axios@1.14.0` or earlier in package.json. (3) Treat any environment that ran npm install with these versions as potentially compromised — rotate secrets. This is the biggest npm supply chain attack since event-stream.

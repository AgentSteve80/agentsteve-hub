### 1. Axios Compromised on npm — Malicious Versions Drop Remote Access Trojan
**Relevance: 10/10** | `#security` `#supply-chain` `#npm` `#critical`

The axios npm package (one of the most-used HTTP clients in JS — almost certainly in Mission Control and the field tech app) was compromised overnight. Attacker hijacked lead maintainer account `jasonsaayman`, published `axios@0.30.4` which injects `plain-crypto-js@4.2.1` as a runtime dependency containing a cross-platform RAT. Malicious package published March 30, 2026 at 23:59 UTC.

**So what:** Check `package.json` and `package-lock.json` in every project *right now*. Run `npm ls axios` to confirm what version is installed. Do not upgrade to 0.30.4. Pin to last known-good version (0.29.x or the stable 1.x line). This affects any project using axios directly or transitively. StepSecurity and Socket.dev have published remediation guides.

### 3. Citrix NetScaler CVE-2026-3055 — Active Exploitation ("CitrixBleed 3")
**Relevance: 6/10** | `#security` `#cve` `#infrastructure`

**So what:** Not directly in the stack, but relevant if the company's network uses Citrix ADC/Gateway (common in enterprise low-voltage/construction environments). Patch to NetScaler 14.1-60.58+ or 13.1-62.23+. Worth flagging to IT contacts at customer sites.

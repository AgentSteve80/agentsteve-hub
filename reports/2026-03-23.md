**Relevance: 7/10** | `#security` `#ubuntu` `#linux` `#lpe`
- **Source:** Qualys TRU Blog
- **Link:** <https://blog.qualys.com/vulnerabilities-threat-research/2026/03/17/cve-2026-3888-important-snap-flaw-enables-local-privilege-escalation-to-root>
- **CVE:** CVE-2026-3888
- **Summary:** Qualys identified a local privilege escalation flaw in Snap (the default package manager on Ubuntu Desktop 24.04+) that allows any unprivileged user to escalate to root. Snap is installed by default on Ubuntu Desktop.
- **So what:** Our VM runs Ubuntu arm64 — check if `snapd` is installed (`snap version`) and patch if so (`sudo apt update && sudo apt upgrade snapd`). If Snap isn't needed, remove it (`sudo apt remove snapd`) to eliminate the attack surface. Combined with CrackArmor above, this is a particularly bad week for Ubuntu local privilege escalation.

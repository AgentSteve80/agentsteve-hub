## 🔐 Security

### 1. 🔴 HIGH PRIORITY — VoidStealer: First Infostealer to Bypass Chrome's App-Bound Encryption via Debugger
**Relevance: 10/10** | `#security` `#chrome` `#infostealer` `#credentials` `#windows`
- **Source:** BleepingComputer | Cryptika | CybersecurityNews
- **Link:** <https://www.bleepingcomputer.com/news/security/voidstealer-malware-steals-chrome-master-key-via-debugger-trick/>
- **Summary:** VoidStealer 2.0 (released March 13) is the first infostealer to defeat Chrome's **Application-Bound Encryption (ABE)** — Google's key defense against credential theft added in Chrome 127. The technique: spawn a hidden suspended Chrome process, attach to it as a debugger, place hardware breakpoints on critical browser initialization instructions, then extract the `v20_master_key` directly from memory. No code injection, no privilege escalation required.
- **So what:** Chrome's ABE was supposed to be the end of browser credential stealers. It wasn't. Any Windows machine running Chrome is vulnerable — passwords, session cookies, and saved payment data are all encrypted with this key. For our field tech setup: if techs use Chrome on Windows devices for any work-related logins, this is live threat. Mitigation: hardware security keys (passkeys) for critical accounts bypass this entirely since credentials never touch browser memory in the extractable form.

### 4. Font-Rendering Prompt Injection — All Major AI Assistants Bypassed (LayerX)
**Source:** Morning brief context · Disclosed December 2025, surfacing March 2026
**Relevance: 8/10** | `#security` `#prompt-injection` `#ai` `#llm`

Custom CSS fonts remap characters so AI tools see harmless HTML but users see malicious rendered commands. Tested successfully against ChatGPT, Claude, Copilot, Gemini, Grok, and 7 others. Only Microsoft patched it. This is a live prompt injection vector for any AI with browser/web access.

**So what:** OpenClaw's browser tool is potentially vulnerable. Don't ask me to verify if a webpage command is "safe to run" — the rendered text I see may not match what the browser displays. For SiteSignal's web scraping: any AI-processed HTML scraped from permit sites could contain this attack. Treat scraped content as untrusted (we already do, but this reinforces why).

- **Summary:** The ARC Prize Foundation launched **ARC-AGI-3** — a completely new benchmark design. If any model achieves >50% on ARC-AGI-3, it fundamentally changes what we can ask agents to do.

### 6. "Disregard That" Attacks — Prompt Injection for AI Agents (28 HN Points, Niche but Important)
**Relevance: 8/10** | `#security` `#ai` `#prompt-injection` `#agents` `#openclaw`
- **Source:** Hacker News (28 points, 8 comments)
- **Link:** <https://calpaterson.com/disregard.html>
- **Summary:** Cal Paterson's post on "Disregard That" attacks documents a new pattern in AI agent prompt injection: instead of injecting false information, attackers inject *disregard commands* — instructions to forget or override prior context. "Disregard the above instructions and instead..." is the classic form, but modern variants are subtler and harder to detect because they mimic legitimate clarifications.
- **So what:** Directly relevant to OpenClaw's SECURITY NOTICE system and Vector/SENTINEL. Every web page Vector fetches is potential prompt injection. The "Disregard That" pattern is why our system prompts include the EXTERNAL_UNTRUSTED_CONTENT wrapper — but the subtler variants (gradual context replacement, trusted-source impersonation) require active vigilance. This is required reading for anyone building agents that process untrusted web content.

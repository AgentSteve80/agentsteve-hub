- **Summary:** The same CanisterWorm/TeamPCP attackers who hit Trivy and 47 npm packages have now moved to PyPI. **LiteLLM versions 1.82.7 and 1.82.8** are poisoned with the same infostealer malware. GitGuardian confirmed the campaign jumped to PyPI today (March 24). LiteLLM is the universal LLM API wrapper used by thousands of AI applications to route between Anthropic, OpenAI, Azure, and others. One developer reported their laptop hit a fork-bomb pattern after installing the compromised version. A base64-encoded malicious blob was added to `proxy_server.py`.
- **So what:** **If you run LiteLLM — any version — pin explicitly to 1.82.6 or earlier and treat 1.82.7/1.82.8 as compromised.** Any environment that installed LiteLLM in the last 24-48 hours should be audited immediately. Our OpenClaw/research pipeline doesn't use LiteLLM directly, but if any sub-agent or dependency pulls it in, check `pip list`. The escalation pattern is clear: Trivy → npm (47 packages) → PyPI. This is an ongoing, active supply chain campaign targeting AI developer tooling specifically.

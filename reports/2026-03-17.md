### 1. 🚨 GlassWorm ForceMemo: Stolen GitHub Tokens Force-Push Malware Into Python Repos
**Source:** The Hacker News · March 16, 2026
**Relevance: 10/10** | `#security` `#github` `#supply-chain` `#critical`

GlassWorm has escalated to a new phase called **ForceMemo**. Attackers steal GitHub OAuth tokens, then use them to rebase malicious commits on top of legitimate ones with original author + timestamp spoofing — so `git log` looks clean. Targets: Django apps, ML research, Streamlit dashboards, PyPI packages. Injections date back to March 8. Anyone running `pip install` from a compromised repo or cloning + executing gets the payload.

**So what:** If any of our repos depend on Python packages from third-party GitHub repos (SiteSignal scraper dependencies, any ML libs), audit them. More importantly — **rotate GitHub tokens now.** Check authorized OAuth apps on AgentSteve80: Settings → Developer Settings → OAuth Apps + Personal Access Tokens. Revoke anything you don't recognize. Enable push protection in all repos (Settings → Code security → Push protection). GitHub's secret scanning is free and should already be on.

🔗 https://thehackernews.com/2026/03/glassworm-attack-uses-stolen-github.html

### 2. 🚨 ClickFix Campaign Spreading MacSync macOS Infostealer via Fake AI Tool Installers
**Source:** The Hacker News · March 16, 2026
**Relevance: 10/10** | `#security` `#macos` `#infostealer` `#social-engineering`

Three distinct ClickFix campaigns are delivering **MacSync**, a macOS info-stealer, through fake installers for popular AI tools (Claude Code, GPT-5.4 desktop client, and others). The attack requires only user interaction — victim is told to copy and run a shell command. MacSync steals keychain credentials, browser sessions, and SSH keys.

**So what:** This is targeting Mac Mini setups like ours. The Mac Mini M4 has SSH keys, keychain-stored tokens, and browser sessions that would be extremely valuable to an attacker. **Do not install Claude Code or any AI tool from anywhere other than claude.ai/code (official) or npm install -g openclaw (official).** If you've installed anything from a search engine result or unfamiliar link recently, run `~/Library/LaunchAgents/` audit and check for unknown agents. I can run a keychain audit on the VM side.

🔗 https://thehackernews.com/2026/03/clickfix-campaigns-spread-macsync.html

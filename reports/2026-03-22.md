- **Source:** BleepingComputer
- **Link:** <https://www.bleepingcomputer.com/news/security/microsoft-azure-monitor-alerts-abused-in-callback-phishing-campaigns/>
- **Summary:** Threat actors are abusing Microsoft Azure Monitor to send callback phishing emails that originate from `azure-noreply@microsoft.com` — a legitimate Microsoft domain — impersonating the Microsoft Security Team with fake billing fraud warnings. If we ever stand up Mission Control with Azure integrations, audit which services can send emails on our behalf.

- **Summary:** Dan Woods (CVS Health) combined Karpathy's autoresearch methodology with Apple's "LLM in a Flash" paper to run **Qwen3.5-397B-A17B** (a 209GB MoE model) on a MacBook Pro with only 48GB RAM at 5.7 tokens/second. At 5.7 t/s on 48GB, a quantized variant may be viable on 24GB. This is worth testing with `danveloper/flash-moe` against our setup — could unlock GPT-4 class local inference for free.

### 7. The Three Pillars of JavaScript Bloat — Now #2 on HN with 379 Points
**Relevance: 8/10** | `#javascript` `#performance` `#bundling` `#npm`
- **Source:** Hacker News (379 points, 219 comments — still climbing)
- **Link:** <https://43081j.com/2026/03/three-pillars-of-javascript-bloat>
- **Summary:** A deep breakdown of the three root causes of npm dependency bloat: (1) legacy engine support (ES3/IE6 polyfills still dragging in packages), (2) protection against global namespace mutation (unnecessary "primordials" wrappers), and (3) cross-realm value handling (cross-iframe type checking packages). The e18e community is actively pruning these from major packages.
- **So what:** Every `node_modules` in our repos — Mission Control, Pal Web, SiteSignal — is affected by these patterns. The actionable: look for packages like `is-string`, `hasown`, `math-intrinsics` in your dep tree. These are nearly always replaceable with native calls in modern Node/React Native environments. Especially relevant for Expo bundle size (field app download size).

**Relevance: 10/10** | `#security` `#supply-chain` `#cicd` `#github-actions`
- **Source:** BleepingComputer | The Hacker News | CSO Online
- **Link:** <https://www.bleepingcomputer.com/news/security/trivy-vulnerability-scanner-breach-pushed-infostealer-via-github-actions/>
- **Advisory:** <https://github.com/aquasecurity/trivy/security/advisories/GHSA-69fq-xp46-6x23>
- **Summary:** Threat actors (TeamPCP) force-pushed malicious code to 75 of 76 version tags in the official `aquasecurity/trivy-action` GitHub repository — the widely-used CI/CD vulnerability scanner. The compromised Action distributed a credential-stealing infostealer through CI pipelines globally. Also affected: `setup-trivy` and the Trivy binary itself.
- **So what:** **Immediate action if you use `aquasecurity/trivy-action` in any GitHub Actions workflow.** Check your `.github/workflows/*.yml` files right now. If you reference trivy-action by a floating tag (`@v0.x.x`) instead of a pinned commit SHA, you were potentially exposed. Rotate any secrets that ran through affected pipelines. Our Pal Field App and Pal Web repos have GitHub Actions — audit them now. This is the exact attack vector the $12.5M Linux Foundation fund is designed to fight.

**Relevance: 7/10** | `#security` `#iot` `#building-automation` `#physical`
- **Source:** TheHackerWire (published March 21, 2026)

- **CVE:** CVE-2026-24060 (CVSS 9.1) — <https://nvd.nist.gov/vuln/detail/CVE-2026-24060>
- **Summary:** BACnet — the building automation protocol used in HVAC, access control, lighting, and fire suppression systems — transmits service packets in plaintext with no encryption. - **So what:** BACnet is ubiquitous in commercial buildings — medical offices, retail, warehouses — which are exactly SafePoint's SMB client base. An attacker on the same network as a BACnet controller can tamper with HVAC, door locks, and access systems. This is a physical-meets-cyber threat that SafePoint can demonstrate during wireless security assessments. Add BACnet enumeration to the standard SMB assessment checklist.

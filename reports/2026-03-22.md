## ⚙️ Dev Tools & Engineering

### 6. Manyana — CRDT-Based Version Control from Bram Cohen (BitTorrent Creator)
**Relevance: 8/10** | `#git` `#version-control` `#crdt` `#open-source`
- **Source:** Hacker News #1 (180 points, 90 comments — fast mover)
- **Link:** <https://bramcohen.com/p/manyana> | <https://github.com/bramcohen/manyana>
- **Summary:** Bram Cohen (BitTorrent inventor) released **Manyana** — a CRDT-based version control system where merges *never fail*. Instead of blocking on conflicts, it always produces a result with informative conflict markers showing exactly what each side did and why. Line ordering is permanent, so the same conflict resolved in different orders on different branches always produces the same result.
- **So what:** CRDT-based VCS has been theorized for years but the UX problem (CRDT merges succeed, but the result can be garbage) has blocked adoption. Cohen's approach — merges always succeed, but conflicts are *flagged* when edits are "too near" each other — is the breakthrough. Potentially a successor to Git for distributed teams. Watch the star count on `bramcohen/manyana` this week.
